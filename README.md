## Descrição

Este repositório contém o código front-end para o website da loja de cosméticos fictícia **"Lazuli cosmetics"**. O projeto foi desenvolvido como parte de um estudo de caso para demonstrar minhas habilidades em desenvolvimento web front-end, focando na criação de uma experiência de compra intuitiva e atraente.

## Funcionalidades

- Catálogo de produtos com opções de com elementos como botôes e indicações ao preçario, para simular uma experiência de compra.
- Página principal com áreas onde são apresentadas informações sobre a empresa, um catálogo de produtos, cards (com promoções, posts), slide animado, área de testemunhos dos clientes, FAQ, formulário e um footer com informações de contacto, localização com mapa em iFrame;
- Design elegante e minimalista, com um layout para dispositivos desktop.

-**CSS3**
